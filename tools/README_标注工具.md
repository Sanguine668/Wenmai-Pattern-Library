# 纹样标注台使用说明

## 启动

```bash
python tools/annotator_server.py
```

浏览器打开 http://127.0.0.1:8765

## 操作

- 左边看图（多图可点缩略图切换），右边看名称/年代/朝代/载体/描述；
- 点 9 个类别按钮把当前文物归入对应纹样类型（龙纹、凤纹、花卉纹、缠枝/卷草纹、云纹、几何纹、文字纹、人物纹、其他）；
- 如果不符合"纹样/图案载体"（例如素面器件、纯器形雕塑），点 **舍弃（无纹样/非载体）**；
- 有自动提示的条目可以直接点 **确认自动提示**；
- 可选次标签、写备注；每一步都会自动保存到 `data_starter/annotations.json`；
- 顶部可筛选：全部 / 待处理 / 有提示 / 已确认 / 已舍弃；
- 点 **导出标注 CSV** 下载 `all_records_annotated.csv`（含 status、motif_type、次标签、备注）。

## 快捷键

- `1`–`9`：对应 9 个类别；
- `D`：舍弃；
- `Enter`：确认自动提示；
- `←` / `→`：上一张 / 下一张。

## 说明

- 判定标准：**图片里是否有可提取的纹样/图案**。素面玉器、无纹饰器件、纯造型雕塑 → 舍弃；如果器物表面是婴戏、仕女、高士、供养人、佛教人物、故事场景等人物题材图案，归入“人物纹”。
- 有图案但类型不确定 → 归入"其他"并在备注里写原因；
- 进度文件是 `data_starter/annotations.json`，不要删除；换电脑时把它一起带走即可继续。
